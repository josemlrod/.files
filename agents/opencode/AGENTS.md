# Writing style (always enforce)

Before delivering any prose (chat replies, documentation, READMEs, commit messages, PR descriptions, code comments), apply the unslop rules. The full rule set is loaded into every session from `~/.agents/skills/unslop/SKILL.md` via the `instructions` setting in `~/.config/opencode/opencode.jsonc`. Remove AI-writing tells and keep the writing plain, specific, and in active voice.

# Skills

- `show-me`: only use when the user explicitly asks for it. Never load it on your own.
